Bem-vindo à documentação de API Syntax! Aqui você encontrará todas as informações necessárias para integrar e utilizar nossa API de forma eficiente.

Abaixo Veja Algumas Rotas

Rota: /clonar-servidor

Descrição: Clona um servidor existente.

Método: POST

Exemplo de corpo da requisição:

{
    "serverId": 123,
    "token-da-conta": "seu-token-aqui",
    "destino": "novo-servidor"
}
